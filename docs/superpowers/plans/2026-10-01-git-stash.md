# Git stash（一時退避 / 復元）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ソース管理パネルに「退避」セクションを追加し、作業中の変更（追跡済み・ステージ済み・未追跡）の退避・一覧・復元（pop）・削除（drop）をアプリ内で行えるようにする。

**Architecture:** main の `gitService` が `git stash push -u` / `stash list -z` / `stash apply --index <sha>` / `stash drop` を、事前検証つきで実行する。退避は番号ではなくコミットの SHA で識別し、実行時に一覧から引き直す。復元は作業ツリーが完全にきれいなときだけ行い、失敗したら `reset --hard` + `clean -fd` で元に戻して退避を残す。renderer は `useGitStashes`（一覧）と `useGitStashOperations`（排他制御つきの操作）を `useAppState` で組み立て、`StashSection` から呼ぶ。

**実装後の注記:** 実装後に単一責任の観点で分割した。main は `gitStashService.ts`（実行）・`gitStashGuards.ts`（事前検証）・`gitPathParsing.ts`、renderer は `useStashPanel.ts`（`useAppState` から分離）・`lib/stashDisplayName.ts`。以下のタスク本文は実行時の記録として残しており、現在の構成は設計書のアーキテクチャ節を参照する。

**Tech Stack:** Electron, React, TypeScript, simple-git, Vitest + Testing Library

設計は [docs/superpowers/specs/2026-10-01-git-stash-design.md](../specs/2026-10-01-git-stash-design.md)。

> **実装後の注記（Task 2 のレビュー対応）:** 以降のコード例のうち、次の 3 点は実装が優先される。
> (1) `stashPush` のメッセージは `-m <message>` ではなく `--message=<message>` の 1 引数で渡す（simple-git の
> blockUnsafeOperationsPlugin が値の `--upload-pack=x` 等を誤検出するため）。(2) `assertStashable` の `status` に
> `--ignore-submodules=all` を付ける（サブモジュールだけの変更で何も退避されないのに成功するため）。
> (3) 検証に「途中の操作（MERGE_HEAD / CHERRY_PICK_HEAD / REVERT_HEAD）」を 初期コミット → コンフリクト → 途中の操作 →
> 変更の有無 の順で足し、文言は `マージ・cherry-pick・revert の途中のため退避できません`。
> **Task 3 のレビュー対応:** `stashPop` は status の確認の後に `ls-files -v -z` で assume-unchanged（小文字タグ）を拒否し、
> pop 成功後の drop 失敗と巻き戻し失敗は専用の日本語文言にする（上の 3 つの文言）。コード例より実装が優先。
> **レビュー対応（復元の戻り値）:** `stashPop` の戻り値を `Promise<StashPopResult>`（`restored` / `dropFailed` / `rollbackFailed`）にした。drop 失敗と巻き戻し失敗は throw せず結果で返し、`popStash` が true を返して再読込させる（`reloadOnFailure` は廃止）。検証には途中の操作（MERGE_HEAD 等）の拒否 `…のため戻せません` も足した。コード例より実装が優先。

Create `src/main/gitStashParser.ts`:

```ts
import type { GitStashEntry } from '@shared/types'

// git stash list -z --format=%H%x00%gs%x00%cI の 1 件は「SHA・件名・日時」の 3 フィールドで、
// 出力はそれらを NUL でつないだ列になる(件名に改行があれば git が空白に置き換える。実機で確認)。
// simple-git の stashList() の解析には頼らない: 解析が git の出力の特殊な場合を覆うか
// 確かめられないため、安全性に関わる識別子(SHA)は自分で解析する(パターン 44)
const FIELDS_PER_ENTRY = 3

// 件名は次の 2 形式(実機で確認):
// - git stash push -m "msg" → "On <branch>: msg"
// - メッセージ無し → "WIP on <branch>: <短縮ハッシュ> <最後のコミットの件名>"
// ブランチ名に ': ' は含まれないため、最初の ': ' までをブランチ名とする。
// detached HEAD では <branch> が "(no branch)" になる
const SUBJECT_PATTERNS = [/^On (.+?): (.*)$/s, /^WIP on (.+?): (?:[0-9a-f]{7,40} )?(.*)$/s]

export function parseStashSubject(subject: string): { message: string; branch: string } {
  for (const pattern of SUBJECT_PATTERNS) {
    const match = pattern.exec(subject)
    if (match !== null) return { branch: match[1], message: match[2] }
  }
  return { branch: '', message: subject }
}

export function parseStashList(output: string): GitStashEntry[] {
  const fields = output.split('\0')
  // 各レコードの後ろにも NUL が付くため、末尾に空要素ができる
  if (fields[fields.length - 1] === '') fields.pop()
  const entries: GitStashEntry[] = []
  for (let i = 0; i + FIELDS_PER_ENTRY <= fields.length; i += FIELDS_PER_ENTRY) {
    const [sha, subject, createdAt] = fields.slice(i, i + FIELDS_PER_ENTRY)
    const { message, branch } = parseStashSubject(subject)
    entries.push({ sha, message, branch, createdAt })
  }
  return entries
}

// 退避の番号(stash@{n})は、他の退避の追加・削除でずれる。実行時に SHA から引き直すための位置の検索
export function findStashIndex(entries: GitStashEntry[], sha: string): number {
  return entries.findIndex((entry) => entry.sha === sha)
}
```

```ts
import { formatConflictFiles } from './gitMergeMessages'

const RESTORE_FAILURE_BASE = '退避を戻せなかったため元に戻しました。退避は残っています'

// 復元(git stash apply)に失敗して作業ツリーを元に戻したときのエラー文言を組み立てる。
// git のエラー文は status の出力のような長い文章で、そのまま見せても原因が分からないため使わない。
// コンフリクトがあればそのファイル名を、無ければ(同名の ignored ファイルがある、パスが
// 追跡済みのファイルに変わっている等)その旨の定型文を添える。git の呼び出し(I/O)とは無関係な
// 文言の組み立てのため gitService.ts から分離している(gitMergeMessages.ts と同じ位置づけ)
export function buildStashRestoreFailureMessage(conflicted: string[]): string {
  if (conflicted.length > 0) {
    return `${RESTORE_FAILURE_BASE}（コンフリクト: ${formatConflictFiles(conflicted)}）`
  }
  return `${RESTORE_FAILURE_BASE}（同名のファイルがあるなど、git が復元を完了できませんでした）`
}
```

```ts
// 退避(git stash)。退避の識別には番号(stash@{n})ではなく退避コミットの SHA を使う。番号は他の操作
// (別の退避の追加・削除、外部ターミナルの操作)でずれ、別の退避を指すようになるため

// 一覧は simple-git の stashList() ではなく stash list -z の出力を自分で解析する(パターン 44)。
// 退避が無ければ何も出力されず、空配列になる
async function listStashes(git: SimpleGit): Promise<GitStashEntry[]> {
  const output = await git.raw(['stash', 'list', '-z', '--format=%H%x00%gs%x00%cI'])
  return parseStashList(output)
}

export async function getStashes(folderPath: string): Promise<GitStashEntry[]> {
  return listStashes(simpleGit(folderPath))
}

// 退避してよい状態かを検証する。前の検証に失敗したら後の git 呼び出しには進まない。
// 英語のエラーを見せる前に日本語で弾くものと、git が成功扱いにするものを事前に判定する:
// - 初期コミットが無いと git は終了コード 1 で `You do not have the initial commit yet`
// - コンフリクト中は終了コード 1 で `needs merge`
// - 退避する変更が無くても git は終了コード 0 で `No local changes to save` と言う
//   (出力の文言に頼らず、事前の状態で判定する。パターン 28)
// rev-parse --verify -q は ref が無いと終了コード 1・stderr 空で終わり、simple-git は reject せず
// 空文字で resolve する(hasMergeInProgress と同じ)
async function assertStashable(git: SimpleGit): Promise<void> {
  const head = await git.raw(['rev-parse', '--verify', '-q', 'HEAD'])
  if (head.trim() === '') throw new Error('コミットが無いため退避できません')
  const unmerged = await git.raw(['ls-files', '-u', '-z'])
  if (unmerged !== '') throw new Error('コンフリクト中のため退避できません')
  const status = await git.raw(['status', '--porcelain', '-z', '--untracked-files=all'])
  if (status === '') throw new Error('退避する変更がありません')
}

// 追跡済みの変更(ステージ済み・未ステージ)と未追跡ファイルを退避する(git stash push -u)。
// ignored のファイルは対象外で、そのまま残る(実機で確認)。メッセージは --message=<値> として 1 つの
// 引数で渡るため、'-' で始まる文字列もオプションとして解釈されない(実機で確認)。
// コミッター情報が無いときは git が作業ツリーを変えずに失敗する(実機で確認)ため、
// そのエラーをそのまま投げる
export async function stashPush(folderPath: string, message: string): Promise<void> {
  if (message.includes('\0')) throw new Error('メッセージに使用できない文字が含まれています')
  const git = simpleGit(folderPath)
  await assertStashable(git)
  const args =
    message.trim() === ''
      ? ['stash', 'push', '-u']
      : ['stash', 'push', '-u', `--message=${message}`]
  await git.raw(args)
}
```

```ts
const STASH_SHA_PATTERN = /^[0-9a-f]{40}$/

function stashNotFoundError(): Error {
  return new Error('退避が見つかりません（すでに削除された可能性があります）')
}

// sha が「形式として正しく」かつ「現在の退避一覧にある」ことを確認する(許可リスト方式。パターン 21)。
// IPC 境界から届く任意の文字列のため、形式で弾いてから git に渡す。さらに、一覧にあることも確認する:
// git は、すでに drop した退避の SHA でもぶら下がったコミットが残っている間は stash apply で復元できてしまう
// (実機で確認)。確認しないと、捨てたはずの退避が復活し、その後の drop が見つけられなくなる
async function findExistingStashIndex(git: SimpleGit, sha: string): Promise<number> {
  if (!STASH_SHA_PATTERN.test(sha)) throw stashNotFoundError()
  const index = findStashIndex(await listStashes(git), sha)
  if (index === -1) throw stashNotFoundError()
  return index
}

// 復元に失敗したとき、作業ツリーを復元前の状態へ戻す。呼び出し前に作業ツリーが完全にきれい
// (未コミットの変更も未追跡ファイルも無い)ことが保証されている前提で、失うものは無い:
// reset --hard が追跡済みの変更と index を、clean -fd が復元された未追跡ファイルを消す。
// clean -fd は ignored のファイルに触れない。未解決ファイルは巻き戻すと取れなくなるため、先に取得する。
// 失敗の検出は例外で足りる: コンフリクトでも、同名の ignored ファイルとの衝突でも、パスが追跡済みの
// ファイルに変わっていても、simple-git は reject する(実機で確認。マージのコンフリクトが
// stderr 空で resolve されたのとは違う)
async function applyOrRollback(git: SimpleGit, sha: string): Promise<void> {
  try {
    await git.raw(['stash', 'apply', '--index', sha])
  } catch {
    const conflicted = parseNulSeparatedPaths(
      await git.raw(['diff', '--name-only', '-z', '--diff-filter=U'])
    )
    await git.raw(['reset', '--hard'])
    await git.raw(['clean', '-fd'])
    throw new Error(buildStashRestoreFailureMessage(conflicted))
  }
}

// 一覧から sha の現在の位置を引き直して drop し、git が出力する `Dropped stash@{n} (<sha>)` の
// <sha> が要求した sha と一致することを確認する。検索と削除の間に退避が増減すると、同じ番号が
// 別の退避を指すため、一致しなければ誤って消した退避を stash store で一覧に戻す。
// 出力から SHA を取れなかったとき(書式が想定外)は、確認できないので成功として扱う
async function dropStashBySha(git: SimpleGit, sha: string): Promise<void> {
  if (!STASH_SHA_PATTERN.test(sha)) throw stashNotFoundError()
  const stashes = await listStashes(git)
  const index = findStashIndex(stashes, sha)
  if (index === -1) throw stashNotFoundError()
  const output = await git.raw(['stash', 'drop', `stash@{${index}}`])
  const dropped = /\(([0-9a-f]{40})\)/.exec(output)?.[1]
  if (dropped !== undefined && dropped !== sha) {
    const message = stashes.find((entry) => entry.sha === dropped)?.message ?? ''
    await git.raw(['stash', 'store', `--message=${message}`, dropped])
    throw new Error('退避の状態が変わったため削除をやり直しました。もう一度操作してください')
  }
}

// 退避を戻して、一覧から消す(git stash pop 相当)。作業ツリーが完全にきれいなときだけ実行する:
// 失敗時の巻き戻し(applyOrRollback)が未コミットの変更・未追跡ファイルを消すため。
// --index で、ステージ済みと未ステージの区別まで退避した時点に戻す(付けないとステージ済みだった
// 変更が未ステージになる。実機で確認)
export async function stashPop(folderPath: string, sha: string): Promise<void> {
  const git = simpleGit(folderPath)
  await findExistingStashIndex(git, sha)
  const status = await git.raw(['status', '--porcelain', '-z', '--untracked-files=all'])
  if (status !== '') {
    throw new Error('作業中の変更があるため戻せません。先にコミットまたは退避してください')
  }
  await applyOrRollback(git, sha)
  await dropStashBySha(git, sha)
}

export async function stashDrop(folderPath: string, sha: string): Promise<void> {
  await dropStashBySha(simpleGit(folderPath), sha)
}
```

```ts
import { useCallback, useEffect, useState } from 'react'
import type { GitStashEntry } from '@shared/types'
import * as gitApi from '../lib/gitApi'
import { useLatestRef } from './useLatestRef'

export interface GitStashesState {
  stashes: GitStashEntry[]
  refreshStashes: () => Promise<void>
}

// useGitHistory の fetchGitHistoryData と同じく、setState を呼ぶ処理をフック本体の外に置く
// (react-hooks/set-state-in-effect に、effect 内のローカル関数由来と認識させる)。
// git 管理外のフォルダでは getStashes が失敗するため、空にフォールバックする
// (リポジトリかどうかは gitStatus が持つ。getBranches/getTags の失敗と同じ扱い)
async function loadStashes(
  folderPath: string | null,
  setStashes: (stashes: GitStashEntry[]) => void,
  isStale: () => boolean
): Promise<void> {
  if (folderPath === null) {
    setStashes([])
    return
  }
  let entries: GitStashEntry[]
  try {
    entries = await gitApi.getStashes()
  } catch {
    entries = []
  }
  if (!isStale()) setStashes(entries)
}

// 退避の一覧の取得と保持だけを担う(操作の実行は useGitStashOperations)。
// 操作の後に呼ぶ refreshStashes が、フォルダ切り替え後に遅れて解決しても古い結果で上書きしない
export function useGitStashes(folderPath: string | null): GitStashesState {
  const [stashes, setStashes] = useState<GitStashEntry[]>([])
  const folderPathRef = useLatestRef(folderPath)

  useEffect(() => {
    let cancelled = false
    void loadStashes(folderPath, setStashes, () => cancelled)
    return () => {
      cancelled = true
    }
  }, [folderPath])

  const refreshStashes = useCallback(
    () => loadStashes(folderPath, setStashes, () => folderPathRef.current !== folderPath),
    [folderPath, folderPathRef]
  )

  return { stashes, refreshStashes }
}
```

```ts
import { useRef, useState } from 'react'
import type { GitStashEntry, GitStatusResult } from '@shared/types'
import * as gitApi from '../lib/gitApi'
import { buildStashDropConfirmMessage } from '../lib/stashConfirmMessage'
import { isGitOperationDisabled } from '../lib/gitUtils'
import type { PendingStashOperation } from '../types'
import { useFileOperationLock } from './useFileOperationLock'
import type { FileOperationLock } from './useFileOperationLock'
import { useRunExclusiveGitOperation } from './useRunExclusiveGitOperation'

export interface GitStashOperationsState {
  /** 実行中の退避操作と、その対象(push は退避がまだ無いので sha が null) */
  pendingStashOperation: PendingStashOperation | null
  /** 退避する。戻り値は実際に実行され成功したか(useAppState が成功時だけ再読込するために使う) */
  pushStash: (message: string) => Promise<boolean>
  /** 戻す。戻り値は実際に実行され成功したか */
  popStash: (sha: string) => Promise<boolean>
  /** 確認 → 削除。戻り値は実際に削除されたか */
  dropStash: (entry: GitStashEntry) => Promise<boolean>
  stashOperationError: Error | null
}

export interface GitStashOperationsOptions {
  /** 削除の確認ダイアログ。テストで差し替えるために注入できるようにする */
  onConfirm?: (message: string) => boolean
}

// useGitBranchOperations と同じ作り: 退避操作どうしは busy ref で排他にし、他の Git 操作が
// ロックを持っている間(lock.isAnyLocked())やリポジトリが無い間も待つ。
// 退避・復元は作業ツリー/index を書き換えるため lockGlobal を取る(実行中の push・ステージ・
// ブランチ操作を待たせる。pull・checkout と同じ理由)。削除は作業ツリーに触れないため取らない
// (取ると削除中に push/pull が無意味に待たされる。ブランチ削除と同じ扱い)
export function useGitStashOperations(
  gitStatus: GitStatusResult | null,
  refreshGitStatus: () => Promise<void>,
  refreshStashes: () => Promise<void>,
  fileLock?: FileOperationLock,
  { onConfirm = confirm }: GitStashOperationsOptions = {}
): GitStashOperationsState {
  const [pendingStashOperation, setPendingStashOperation] = useState<PendingStashOperation | null>(
    null
  )
  const isRunningRef = useRef(false)
  const [stashOperationError, setStashOperationError] = useState<Error | null>(null)
  const localFileLock = useFileOperationLock()
  const lock = fileLock ?? localFileLock
  const isDisabled = isGitOperationDisabled(gitStatus)

  // ステータスと一覧は互いに独立した IPC のため並行して再取得する
  const runOperation = useRunExclusiveGitOperation(
    () => Promise.all([refreshGitStatus(), refreshStashes()]).then(() => undefined),
    setStashOperationError
  )

  const isBusy = (): boolean => isRunningRef.current || lock.isAnyLocked() || isDisabled

  const makeSetBusy =
    (pending: PendingStashOperation) =>
    (busy: boolean): void => {
      isRunningRef.current = busy
      setPendingStashOperation(busy ? pending : null)
    }

  const pushStash = (message: string): Promise<boolean> =>
    runOperation({
      isBusy,
      setBusy: makeSetBusy({ kind: 'push', sha: null }),
      onStart: lock.lockGlobal,
      onEnd: lock.unlockGlobal,
      execute: () => gitApi.stashPush(message)
    })

  const popStash = (sha: string): Promise<boolean> =>
    runOperation({
      isBusy,
      setBusy: makeSetBusy({ kind: 'pop', sha }),
      onStart: lock.lockGlobal,
      onEnd: lock.unlockGlobal,
      execute: () => gitApi.stashPop(sha)
    })

  const dropStash = async (entry: GitStashEntry): Promise<boolean> => {
    if (!onConfirm(buildStashDropConfirmMessage(entry.message))) return false
    return runOperation({
      isBusy,
      setBusy: makeSetBusy({ kind: 'drop', sha: entry.sha }),
      execute: () => gitApi.stashDrop(entry.sha)
    })
  }

  return { pendingStashOperation, pushStash, popStash, dropStash, stashOperationError }
}
```

Create `src/renderer/src/components/source-control/StashSection.tsx`:

```tsx
import { useRef, useState } from 'react'
import type { StashPanelState } from '../../types'
import StashItem from './StashItem'
import StashMessageDialog from './StashMessageDialog'

interface Props {
  stash: StashPanelState
  /** 他の操作中(ステージ・ハンク操作・commit・pull・ブランチ操作)で押しても no-op になる状態 */
  isBlocked: boolean
}

// 「退避」セクション(見出し・件数・「退避する」ボタン・一覧)。メッセージ入力ダイアログの開閉と、
// 閉じたときのフォーカスの戻し(パターン 22)をここで持つ。操作の実行・排他・確認は
// 呼び出し元(useAppState / useGitStashOperations)の責務
export default function StashSection({ stash, isBlocked }: Props): React.JSX.Element {
  const [isDialogOpen, setIsDialogOpen] = useState(false)
  const pushButtonRef = useRef<HTMLButtonElement>(null)
  const isPushing = stash.pendingOperation?.kind === 'push'
  const isDisabled = isBlocked || stash.pendingOperation !== null

  // ダイアログを閉じたら(OK・キャンセル・Escape・オーバーレイクリックのいずれも)ボタンへフォーカスを戻す。
  // OK の場合は、ボタンが実行中に disabled になる前にフォーカスを戻すため、onPush より先に呼ぶ
  const closeDialog = (): void => {
    setIsDialogOpen(false)
    pushButtonRef.current?.focus()
  }

  const handleSubmit = (message: string): void => {
    closeDialog()
    void stash.onPush(message)
  }

  return (
    <section className="source-control-panel__section stash-section">
      <div className="stash-section__header">
        <h3 className="source-control-panel__section-title">退避（{stash.entries.length}）</h3>
        <button
          ref={pushButtonRef}
          type="button"
          className="stash-section__push"
          aria-label={isPushing ? '退避中' : '変更を退避する'}
          disabled={isDisabled}
          onClick={() => setIsDialogOpen(true)}
        >
          {isPushing ? '退避中...' : '退避する'}
        </button>
      </div>
      {stash.error !== null && (
        <p className="stash-section__error" role="alert">
          {stash.error.message}
        </p>
      )}
      {stash.entries.length === 0 ? (
        <p className="stash-section__empty">退避はありません</p>
      ) : (
        <ul className="stash-section__list">
          {stash.entries.map((entry) => (
            <StashItem
              key={entry.sha}
              entry={entry}
              pending={stash.pendingOperation}
              isBlocked={isBlocked}
              onPop={(sha) => void stash.onPop(sha)}
              onDrop={(target) => void stash.onDrop(target)}
            />
          ))}
        </ul>
      )}
      {isDialogOpen && <StashMessageDialog onSubmit={handleSubmit} onCancel={closeDialog} />}
    </section>
  )
}
```
